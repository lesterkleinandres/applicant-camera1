Camera help

If the camera does not start, check its connection and browser permission.

Please check the following:

1. Make sure you are using Google Chrome or Microsoft Edge.

2. Make sure your computer has a working camera.

3. In Chrome, open the camera permission settings for this Web App and select Allow.

4. If the permission was previously blocked, reset the permission and reload this page.

5. Close other applications that may already be using the camera, such as Teams or Zoom.

The photo will be saved to the Applicant Photos and Signatures folder and inserted into the applicant form.
