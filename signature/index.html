First-time setup or connection help
  1. Connect the STU-540 to this Windows laptop by USB and use desktop Chrome or Edge.
  2. Choose Connect signature pad. In the browser's device list, select the STU-540 and choose Connect.
  3. Sign on the pad. Use Clear to start over, or Save Signature to insert the signature in the TIPON form.
  4. If no pad appears, reconnect the USB cable and close other apps or tabs using it. The STU-540 must be in USB HID mode.
  5. If your organisation blocks USB access in the browser, ask IT to allow this capture page to use the pad.

Your signature is sent back to the TIPON form only when you choose Save Signature. Keep its signature dialog open until saving finishes.
