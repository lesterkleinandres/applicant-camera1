First-time setup or connection help
  1. Connect the STU-540 to this Windows laptop by USB.
  2. Install Wacom STU SigCaptX for Windows from the Wacom Developer Dashboard (Wacom Device Kit → STU SDK for Windows Desktop).
  3. Install the Wacom STU driver, then reopen your browser if the installer asks.
  4. Use Chrome or Edge. If asked, allow this page to connect to devices on your local network so it can reach the Wacom service on this laptop.
  5. Close other applications using the pad. The pad must be in USB HID mode.

Your signature is sent back to the TIPON form only when you choose Save Signature. Keep its signature dialog open until saving finishes.
